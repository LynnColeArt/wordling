## Running without handoffs

- Start with the [everyday acceptance journeys](milestones/everyday-editing/acceptance.md), [qualification evidence map](../../tests/everyday_qualification/coverage.md), [reference environment](../../docs/research/reference-environment/README.md), [command scenarios](../../docs/research/command-scenarios.json) and [mission matrix](acceptance-matrix.json). Reuse the candidate builder and suite runner under tests/everyday_qualification, run focused recovery/table/merge scripts explicitly where needed, and use scripts/reference for DOS captures.
- For each case, record the ID, reference and candidate identities, fixture, inputs, expected and observed results, evidence path and verdict. Use pass, mismatch, untested or blocked and record the exact open branch for partial coverage. Compare native bytes on unchanged saves. For edited saves, compare intended effects, preservation and interoperability. Declare comparison tolerances before running the cases.
- On a mismatch, reproduce it, capture the original behavior, fix it, rerun the case and neighboring workflows, and continue. Investigate harness failures separately and keep independent batches moving. Record progress and findings in the workspace. Rebuild the preview after the everyday gate and after final acceptance.
- Routine passes, failures, repairs and builds require no check-in. Contact Lynn only when access, physical input or a product decision genuinely requires her. Bundle those requests and keep independent work moving. The final report gives the exact preview build, evidence coverage, independent verdict and any open gaps.

## Platform testing after Linux

Finish Linux qualification first. Then use Pink Menace Codex to run the macOS build and native document round trips. Run the Windows build from PowerShell when Windows is available. On each host, check terminal keys and mouse input, native save and recovery, and whether the platform's filesystem supports the existing replacement and backup guarantees. Use the Linux and DOS fixtures to compare native bytes and document behavior.
