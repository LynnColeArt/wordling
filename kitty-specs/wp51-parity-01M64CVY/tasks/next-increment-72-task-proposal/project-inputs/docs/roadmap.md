# Two-mission roadmap

## M1 — WordPerfect 5.1 parity

Status: starting. Complete original-app parity is the objective; an MVP is not
the acceptance boundary. Research, specifications, planning, and implementation
milestones all belong to this mission.

Suggested sequencing, subject to the implementation plan:

1. Reconcile manual coverage; identify and fingerprint a reference installation.
2. Establish original-format fixtures, lossless reading/writing, and safe editing.
3. Establish classic terminal interactions and Reveal Codes over the same model.
4. Implement formatting, fonts, pagination, printing, and document preview.
5. Implement structured documents, automation, language tools, and utilities.
6. Close all coverage gaps and run original-application acceptance scenarios.

Milestones are not additional missions. Ordering can change with dependencies.
Features discovered during manual study expand the tracked obligations rather
than disappearing outside a frozen short list.

Exit: complete inventory reconciliation; every obligation verified against the
declared original baseline; no unresolved destructive file or semantic mismatch;
documented compatibility limitations resolved or explicitly adjudicated by Lynn.

## M2 — Modern conveniences

Status: planned, not started; depends on M1 acceptance.

Confirmed scope: PDF export from document layout. Additional convenience features
remain candidates until selected. Existing backup, mouse, keyboard configuration,
and other original features must not be incorrectly deferred into M2.

Exit criteria will be specified at mission start. All permanent charter and
native-format requirements remain binding. Modernization cannot introduce a new
native format or require a Wordling sidecar to use a document.
