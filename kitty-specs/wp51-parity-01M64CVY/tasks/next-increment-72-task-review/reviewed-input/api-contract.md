# Proposed NEW owned API; actual dependencies distinguished

These signatures are a proposed minimal contract for independent TASK review, not existing APIs or authorization to edit source. Naming/shape changes need resolution before promotion, not implementation-time guessing.

- `Compile(primary native.Program, expectedPrimary native.Source, limits Limits) (Plan, error)` creates an immutable by-value closed-form semantic plan. `Plan.Valid() bool`; zero/failed plans invalid.
- `Plan.Evaluate(data explicit.Data, expectedSecondary native.Source, recordOrdinal int) (Result, error)` computes ONE record under captured limits; no caller instruction/Inspection/result/budget callback. Missing field preserves the existing typed `*explicit.ExplicitFieldMissing` in the returned error chain. Zero/invalid/out-of-range record refuses.
- `Result.Valid() bool`, `Result.Bytes() ([]byte, error)`, `Result.Provenance() (Provenance, bool)` supply a defensive result and copied trace. No public proof constructor, result-from-bytes, IR mutator, source rebind or Resume API.
- `Limits` has positive capped `PrimaryTokens`, `BodyBytes`, `WorkUnits`; default/maxima4096,65536,1048576. No zero-as-unlimited/default. Fixed allocation/trace/consumer bounds in finite-bounds.md are not overridable.

Plan retains the actual Program and owner, compiled whole-primary form and bounded source references privately. Evaluate receives the actual Data proof; expectedPrimary/Secondary are genuine distinct Source owners, not hashes. Coincident bytes from a second independent Parse are NOT interchangeable owner authority. An expected source must match its corresponding input; there is no assertion that primary and secondary share an owner. Independently parsed equivalent complete input pairs remain valid when EACH corresponding expected Source is correct.

Provenance records the actual Primary and Secondary Source owners, one-based record, emitted output ranges and exact source-owned literal/HR/field content references. It records the IFBLANK2 decision/reference even when that field emits no bytes, and preserves the enclosing native.Record/native.Field (including EF/HR/EOR/tail/interstitial spans) for field accesses. Returned mutable slices/nested record Fields/Interstitial must be copied. Native spans cannot be invented from offset arithmetic; use the authentic captured spans. Copied provenance/inspection is diagnostic, cannot recompile/retarget execution or become a writer capability. No output trace claims source coverage for unselected branch bytes; whole-primary validation separately covers BOTH branches before evaluation.

Actual dependency APIs have been read from their immutable Git sources: native.Parse→Image.View(Primary)→View.Admit returns immutable Program; Program.Inspect returns copies; Program.Bytes validates source-owned Span. explicit.Admit takes a Secondary View plus expected Source and retains all existing blockers/findings; Data.Field is one-based and returns Value or typed ExplicitFieldMissing. Value.Bytes/ExplicitlyEmpty/Provenance use the private accepted proof. Generic Secondary Supported/Admit remains blocked. No new overload/method is assumed on those dependencies.

The real compiled consumer calls every new consuming API and reports its results. Compile/Plan/result methods may not exist only for tests. No exported function may become an unused architectural placeholder for a later full Merge engine.
