## Claim boundary and necessity

The current native reader provides immutable source-owned spans and copied semantic inspection, but no reusable proof that an entire Secondary belongs to this closed explicit-field DATA subset. Public Inspection/Record/Field/JSON can be replaced or mutated; passing them to a future binder as if already qualified would lose the predicate/source guarantee. Moving that whole-source proof into a sibling package lets later consumers obtain value bytes and explicit presence from private immutable proof state without repeating an observer's classification. That guarantee is distinct from, and does not repair, the existing generic Secondary execution refusal.

The NEW qualification workflow is meaningful because it must call actual native.Parse→captured Secondary View→new Admit(expectedSource)→Data.Field→Value getters before diagnostics exist. Its operational purpose is qualifying the new capability and its error/source/explicit-empty guarantees against immutable paired evidence; it is a maintainer research successor, not an ordinary product merge command. The old53 observer cannot exercise a capability that does not exist, and its mutable JSON cannot supply it. This is adequate concrete non-test reachability at the domain-contract delivery level, provided the later task/code review rejects the explicitly forbidden alternatives: new package unused by that workflow, observer/scanner clone, helper-only tests, expected-JSON replay or an invented app QoL command used as a reachability fiction. ## Public API and source ownership feasibility

The actual approved native.View wrapper contains only a private pointer to immutable viewState. Copying the WHOLE View value once, then using ONLY that captured value's Inspect and Bytes, preserves the private accepted source/role ownership without accessing private fields or keeping a caller-replaceable wrapper pointer. Inspect already defensively copies Records/Fields/Interstitial and findings; Source.Equal compares private state identity, not hashes. Captured inspection/spans kept private can establish proof, while caller-supplied observations cannot. Independently parsing equal bytes produces a foreign Source. Unsynchronized mutation during the capture call remains outside the Go contract; subsequent immutable reads require genuine race acceptance.

The sibling can use public native.Source/Span.Bounds/View.Bytes and copied reader records/tokens to verify coverage. Bounds are arithmetic observations only: every byte access still goes through the captured View.Bytes with its source-owned Span. No new Span constructor, private native field access, second framing/token/operand decoder or duplicate native IR is needed. The actual body start can be bound to the approved reader token/record coverage; hardcoding fixture offset324 or trusting supplied integer ranges would be nonconforming. Admission may make one bounded full-source capture/export as needed for EOF/custody, not a full-image Export per field. Positive native limits are guaranteed by accepted Parse ownership; capped findings still refuse, so effective accepted record counts may be below the general MaxRecords depending on the selected finding cap.

Data and Value by-value copies are legitimate immutable proof aliases, not newly issued authority and not mutable setters. Getters must return copied bytes/provenance, never private backing/inspection slices. Zero/nil/wrong-source/role/invalid objects refuse. Missing lookup returns typed ExplicitFieldMissing plus invalid Value; it must not become a valid empty value. A valid zero-length Content with its OWN EF is explicitly empty; the equally zero-length UNADDRESSED tail is never a field. Nil []byte alone cannot signal presence. No API promotes Data to native.Program or accepts caller Inspection/Record/Field/JSON/output tables as proof.
