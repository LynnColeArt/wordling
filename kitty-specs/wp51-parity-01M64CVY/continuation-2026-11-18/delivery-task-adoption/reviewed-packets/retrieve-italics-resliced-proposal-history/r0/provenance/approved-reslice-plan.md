This is an unreserved planning hypothesis, not approved tasks, implementation,
registration or a compatibility claim. The original reviewed single-package
proposal remains immutable in `../retrieve-italics-proposal/`. Temporary names
WP106/WP107 and T344–349 must be checked against the real registry before use.

The combined ownership of native document code and editor/TUI tests contracts
document→layout→editor into a cycle. Keep those actual owners distinct because
the delivery has two independently reviewable responsibilities: native insertion
safety, then genuine public Retrieve and file publication. Preserve every former
test and every actual predecessor across the two packages. No ownership, old
dependency, historical approval or lane guard is removed or relabeled.

Every former native test belongs to the core; every former rooted editor/TUI
test and every Runtime save/reopen check belongs to public integration. Evidence

document-code ownership bridge. Both scopes and their union require review.

edit is explicitly amended above; no chronology is fabricated. Review must
accept this test sequencing or return a better real package boundary.

save qualification remain mandatory later acceptance gates. Neither package
promotes the command audit, E3 or the mission matrix. Full Mission1 and ticket7
