# ADR0003: Conditional admission for existing ASCII/Bold native documents

Status: proposed; conditional on independent WP23 contract approval. This ADR
permits no production writer before that approval. It describes a first bounded
milestone in M1; complete plain WP5.1 parity remains the mission obligation.

An existing native image may be read losslessly without being safe to rewrite.
Original Retrieve/SaveAs changes the sampled body start from324 to564 and retains
deleted extents; printing can also leave index-unowned prefix residue. The actual
approved reader accepts these observed variants and preserves their exact bytes.
Their presence does not grant semantic write permission.

The first proposed mutation admission therefore requires the complete checked
header/index/packet/body contract in
[contract.md](../research/continuation/native-edits/contract.md) and its
[field ledger](../research/continuation/native-edits/field-ledger.json).
The accepted input owns its whole prefix. Use checked indexed packet locations,
complete nonoverlapping ownership, the qualified Standard Printer/Courier resource
payloads and packet8 count0. The two font descriptor-match hash variants are
qualified exact inputs; their scalar bytes are preserved. The printer-select
counter is admitted only at its observed fresh-document value1. Other original
counter values remain valid read-only observations and refuse this first writer.

Copy the input's prefix, not a template. With printable ASCII and at most two
sequential matched nonnested Bold pairs, the admitted prefix has no reference into body text.
Body termination is actual EOF and no prefix field stores body length. A supported
body change may set only indexed packet6 bit3, the documented must-format flag;
all other prefix bytes and pointers remain identical to the owned input. A no-edit
export remains byte-identical under FC002 even where original WP cache behavior
differs. Preserve code identity rather than interpreting display glyphs as text.

Unknown packets, incomplete prefix ownership, aliases, deleted/FastSave entries,
nonzero graphics, C0/other character sets, additional attributes, nested/formatter
functions, unsupported resources and unexplained fields/relationships refuse
semantic mutation. No abbreviated prefix reconstruction, general relocation,
resource recomputation, new-document writer or production serializer is selected.
The research inspector is an admission audit; the actual approved Go reader
continues to own read-only native parsing.

The original command contract is the exact accepted local subcase ledger and two
fresh-copy witnesses under
[native-edits](../research/continuation/native-edits/). Context matters: normal
code deletion can ask a question; Reveal deletion has separate evidence. Block
No/F1/Escape retains an active block, followed by separately captured F1 cleanup.
History recipes use independent master copies; Restore retention/grouping and
cursor outcomes are literal observations of those recipes. Untested contexts
remain unsupported rather than inheriting a generic cancel/undo rule.

Later implementations must call the candidate verifier with a lawful scratch
file, exact producer/hash/expected body and same-profile complete reference print.
Acceptance requires original Retrieve, a subsequent declared edit, print job
completion, Save, captured final DOS/cursor, immutable seed/source, literal native
field relationships and actual reader reopen/export. Exact raw printer comparison
has no geometry/pixel tolerance and no physical font/printer qualification claim.
An original-authored verifier smoke proves that verifier path only, not a Go
serializer, terminal product or whole canonical scenario.

WP25–29 must consume the independent WP23 review outcome, actual admission and
branch tables, and explicit unsupported variants. General native mutation,
new-document creation, full editing/history/storage/layout/character/platform
scope and the remaining38 requirements/91 groups remain open. PDF belongs to
optional M2 after genuine M1 acceptance. A missing relationship or required
original observable blocks the dependent writer slice and requires a scoped
followup; it cannot be replaced by a passing refusal-only milestone.


The required repair-Restore output qualifies a second sequential matched pair,
including an empty first pair. This two-pair bound is an initial implementation/
qualification policy, **not an original format limit**. Preserve literal On-Off-On
bytes and the observed cursor; never collapse them. A prospective output above
this bound refuses before document/history mutation. General higher counts and
repeated Restore beyond the bound remain full M1 obligations. The complete field
inventory and two fresh source/final prefix comparisons show no new body reference
or stored pair count; that field argument gives no untested command permission.
