## Important source distinctions

- **Cancel, Undelete and macro cancellation are distinct.** WB07 uses F1 at menus, an exit question and native deletion history; it never executes macro CANCEL ON/OFF. Its broad A2 thematic association is not macro coverage. After entering Help, pressing a feature key selects a topic rather than editing the document. Help/menu return state must remain exact.
- **Timed backup appears in WB08 prose.** The1989 source describes30-minute periodic backup, a wait notice, deletion on exit and later retrieval guidance. This refines S1/S2 research; it does not establish March1992 behavior, a configured original backup run or equivalence to current modern recovery. The later recovery lesson is not expanded here.
- **Doc1/Doc2 switching is not split windows.** WB09 opens, copies between, clears and closes independent document screens. It has no Ctrl-F3 Window/height command, so it supplies no original split-window geometry evidence and does not close CMD51-008/I1’s split branch.
- **Original source versus edited output matters.** WB08 retrieves MUSICBOX.WKB and creates MUSICBOX. WB09 explicitly returns to MUSICBOX.WKB to copy its rough-draft material, not the edited output. Paragraph copy includes following hard returns; copied Block turns off before switching. Both source bytes and each receiver/caret/history/dirty state need independent later proof.
