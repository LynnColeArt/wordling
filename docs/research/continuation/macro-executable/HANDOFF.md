# WP37: production loaded-session macro host

This package connects the existing Bubble Tea executable to the approved editor36
adapter, VM35, rooted WPM34 acquisition and loaded native writer/storage. It does
not close FR012 or M1. No reference guest was launched for WP37.

`Alt-F10` opens the actual Macro prompt. Enter schedules the rooted read, then
compile and sixteen-work-unit execution slices as separate `tea.Cmd` workers.
The ordinary reducer owns native text, cursor, history, dirty and source state;
there is no alternate document or serializer. A private nonzero-sized UI token
binds every Model transition from Open onward. Private CPU tickets and IO receipts
bind single dispatch/delivery; a stopped frame cannot consume a later child read.
Runtime.Close cancels the actual worker context, joins started CPU/IO workers and
then closes the same directory. Compile/Resume are off the UI thread but their
approved APIs are not preemptible. Callback latency is not guaranteed by the
sixteen-unit budget. Shutdown outcomes retain copied scalar diagnostics, not
source images, opaque native revisions or private acquisition proofs.

The original observed Esc,3,Alt-F10 sequence uses the approved Repeat3 total
budget. Shift-F3 targets the second buffer only after a real native Retrieve;
there is no new-native constructor. Macro-name F1, exact missing-name recovery,
and Alt-F10 during Save-name retain their qualified original distinctions. Live
F1 is explicitly unsupported for the available VM command subset; it is not an
alias for host containment. HostStopMacroMsg and OS shutdown remain separately
identified. Normal root/nested-child QUIT uses approved39 stop-all semantics,
retains partial literals and allows subsequent ordinary manual READY input.

## Explicit host configuration

The CLI requires an operator-selected absolute root and a closed profile enum.
`local-flat` remains strict. `macro-cout` additionally maps ONLY literal `C:\OUT\`
and empty basename prefixes to the SAME already-open Directory capability through
approved editor.Config/Location. This lets unchanged original212/213/230 and39
sources resolve their recorded literal nested names. It is an explicit Linux host
adaptation authorized by the mission orchestrator, not general DOS path parity.
No case folding, slash normalization, traversal, arbitrary drive, prefix stripping
or macro rewrite was added. Profile/root/arguments/input hashes are captured for
every actual PTY case. Reopening the same path creates independent authority.

spaces, before execution. The observer now checks bounded current VT cells and
retains raw bytes. Development02/03/04 passed actual literal/nested/Repeat cases.
The first final invocation failed before creating any process because the output
parent did not exist; its traceback is retained, then the parent was created and
final01 ran all54. The initial source-audit mistakenly included owned changed
main.go as an inherited dependency; its failure is retained and that owned path
was correctly excluded. No product source was changed for either preflight fix.

Six initial behavioral mutants were killed; removing Close cancellation survived
a queued-only assertion because the separate closed-worker guard also refused
work. An explicit assertion of the real flow context cancellation was added;
all seven final mutants are killed. That test-only addition occurred after PTY;
the source audit lists it explicitly, the production binary is identical, and
final checks/race/fuzz include the added assertion. Initial passing fuzz/checks
remain historical, not silently overwritten. Resource wall times are measured
observations on this host, not DOS limits or hard scheduling guarantees.
