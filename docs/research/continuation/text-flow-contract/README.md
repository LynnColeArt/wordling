# WP49 offline text-flow evidence

This research component recomputes the selected original fourteen corpus's
source-bound facts. It does not implement a layout engine, printer emitter, native
writer or a new original experiment. The closed rendering/printing rule set is
**unresolved**; no downstream permission follows from this result.

Public commands, from this actual dependency-composed worktree:

```
python3 scripts/reference/text_flow_contract.py plan
python3 scripts/reference/text_flow_contract.py check --output docs/research/continuation/text-flow-contract/offline-result.json
python3 scripts/reference/text_flow_contract.py result docs/research/continuation/text-flow-contract/offline-result.json
python3 docs/research/continuation/text-flow-contract/tests/test_contract.py
python3 docs/research/continuation/text-flow-contract/tests/fuzz_contract.py
```

`check` authenticates all6,348 accepted capture artifacts against immutable14 Git
blobs and run records, reads all64 native snapshots and32 complete PRN streams,
reuses unchanged approved14 token/field/membership diagnostics and runs the actual
approved inherited Go wp51 reader against every native image for exact export.
`result` recomputes those sources/facts and rejects changed/rehashed rules or
bindings. `plan` stays offline; `run` always refuses Stage2NotJustified. No guest,
QMP connection, oracle lock, master/resource image read or resource extraction
method is invoked. The historical private resource hash records are read as
public metadata only. Private manuals are verified by streamed hashes; no manual
or original resource text/bytes are published.

[contract.md](contract.md) explains documentary fields versus empirical rules,
source/counterexample/unsupported predicates, before/after protocol changes,
printer initialization gaps and no-new-original decision. [budget.json](budget.json)
declares actual input/allocation/traversal/fuzz policies; bounds are research
limits, not original DOS capacity, physical printer or product SLO claims.

Original raw bytes are never normalized or rewritten. Owned JSON outputs replace
a directory entry, protecting a source inode reached by hardlink; an external
symlink or output outside the owned subtree refuses. Native reading and the Go
bridge write only bounded temporary research/build artifacts. No copied Go source
is installed as a second parser/product package. No42 helper/source is consumed;
explicit prerequisites07/14/21/39/43 remain.

Initial development logs are preserved: a syntax error, an overly strong global
body-equality assumption contradicted by the actual dormant boundary protocol,
and the first semantic tests' JSON tuple roundtrip/opaque-first-field assumptions.
The source now retains exact observed differences and JSON-stable shapes; tests
derive a real nonopaque field. These failures are not original runs and are not
rewritten as passes. All38/91/36/nested full-M1 obligations and the M2/PDF boundary
remain; this is a research handoff awaiting independent review.
