# One cumulative E/P envelope and resource states

DESIGN ONLY. Exact current ABI lacks sufficient live observations/job delegation; this file is a required future contract, not a claim that counters already exist. No split independent budgets/two sessions/newAttempt escape. ONE Controller Envelope, ONE P worker/session and ONE original child per leaf; generic post-stop helper phase is separate from foreground-count policy, with every helper charged to the same totals.

## State chain and source of authority

UNAUTHORIZED -> source/grant verified -> owned Batch ticket charged -> physical-held -> P workspace/preparation -> causal foreground OWNED -> E protocol -> E normalDOS -> E terminal-wire + P passive-exit + E stopped/socket -> P stopped snapshot REAL successor -> proposed StoppedReadLease -> monitored readonly derivations/output leases -> required export/absence/master checks -> physical release+immediate notify -> readonly semantic audit -> complete prior qualification -> NEXT.

Any fault -> permanent whole-plan HALT, unknown launch never0; containment is not normal stop/export authority. Stop unknown leaves logical reservation unresolved for root diagnosis. Failed/unknown/contained image is never opened/extracted. Root logical release only through actual full completion/explicit safety decision, never automatic physical flock close. No reuse of old grants/IDs.

## Reservations and missing public counters

Envelope owns strong actual Session + source-bound E stream + Batch/parent-directory capabilities. Its constructor consumes real issuer authority, never public observations alone. Before each effect reserve bounded maximum bytes/messages/job/FD/time from remaining global credits; a read requests at most its granted remaining count. Refresh actual usage from proposed public server snapshot, reconcile only genuinely observed completed effects. The usage reply itself has a reserved response upper bound. Background worker enforcement remains active during slow client protocol. On lost/late/unknown response keep entire reservation spent and halt; no authority recovery by rehash.

At exact2c0dec only close() returns a subset of P totals; E55 process lacks RSS/process/FD/disk-IO accounting. Therefore no current split-reservation scheme is represented as a complete solution. The source-review addendum must define actual missing measurements/enforcement and test overflow during control-reply backpressure/streaming/terminal phase. If public fields cannot prove a dimension, disclose UNKNOWN/BLOCKED, not0. No private field reads, global patch or duplicate supervisor.

## Output and root-directory custody

Controller first owns a fresh run-parent through actual OwnedFile/root directory creation and retained nofollow descriptor; input plans/paths are data. P NewWorkspace creates the absent declared child directory and binds its own fd/source journal. E does not derive authority from returned path facts; it holds its parent capability plus actual Session and all server-issued resources. Every P artifact operation requires real issuer/root/epoch checks.

Only genuine stopped WorkingLease successor can enter seal_stopped, and only successful server derivation issues output handles. E reads actual output through bounded server streaming, writes its OWN no-clobber public OwnedFile namespace and binds full bytes/hash to StoppedRun/leaf/source. An output manifest/hash/success boolean alone cannot authorize access, native validation or completion. Missing required export versus declared absent artifact are separate outcomes. No out-of-contract mcopy/cp against a path, failed-HD read, overwrite, reset or stale-result authority.
