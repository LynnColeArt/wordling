## Greeting without copying the decoder

Use the approved E55 peer.connect public factory and approved13 QMP class. A NEW E factory supplies a source-defined subclass/composition adapter whose public read method installs a bounded stream BEFORE invoking the approved base decoder's FIRST read. The approved peer sets socket/stream before calling q.read, so this public factory hook exists. Adapter must not call inherited __enter__ or duplicate JSON/QMP parsing. Its bounded readline facade accepts only <=4096B per frame, <=64 events/command, <=64KiB command aggregate and remaining absolute Envelope time; it preserves exact bytes and reports partial/overlong/no-newline/EOF. Socket timeout is min(selected remaining, absolute remaining), never a fresh unlimited reset. Actual writes are bounded/no-buffered-late-flush; foreign peer receives zero bytes. ## Terminal boundary

Nonterminal failures cannot become terminal success. After a source-authorized quit send, TerminalExchange is issued only by actual bounded QMP wire collection for ONE quit and actual successful empty reply, exact ordering/source/peer/causal identity bindings, immutable no-clobber audit persistence. A final causal exit can make live verify_current impossible: capture exact terminal bytes/EOF facts, then require P passive finish (no signals/fault/direct reap), actual E socket absence/same-owned stop, and the earlier normalDOS witness. Do NOT issue READY/current identity after exit or represent terminal bytes as proof of unseen exec history. Preserve identity_at_exit_unproved/daemonUNKNOWN.

TerminalExchange is not P ownership, StoppedRun is not native validity, normalDOS is not inferred from exit0. Missing reply, partial/EOF/error, unknown identity before quit, host containment, fault/persistence loss or absent normalDOS prevents StoppedRun/exports. E55 wire_semantics/issued receipt invariants are reused; NEW adapter receipt issuer/transport join must be independently reviewed, not instantiated through old private _Receipt or reconstructed JSON.
