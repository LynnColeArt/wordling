an empty pair, as an **initial implementation/qualification bound, not an original
format limit**. Preserve On-Off-On literally. A prospective result above the bound
must refuse before document/history mutation. Higher counts/repeated Restore beyond
that bound remain explicit full M1 obligations. Field-level format facts and the
bounded no-new-body-reference inference are separated in the contract/proof.

entries; post-print reuse can leave index-unowned residue. Actual reader acceptance,
opaque lossless preservation and mutation admission are separate. The first writer
refuses deleted/alias/unowned variants. No field is normalized; each differing byte
is assigned an indexed field/extent or fails. Unowned output residue must equal the
same source bytes; live field changes must match the exact observed lifecycle.

Each selected changed output has original Retrieve → declared subsequent edit →
complete selected-profile print → Save, stopped-image extraction and final DOS
