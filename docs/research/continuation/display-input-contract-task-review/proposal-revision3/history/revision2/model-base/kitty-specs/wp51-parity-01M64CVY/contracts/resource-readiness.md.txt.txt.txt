## Exact field-contract blockers

Pinned SDK PDF59,204,95 and REF PDF346 were rendered and visually inspected using the read-only PDF workflow. These clarify what the source actually prints; they do not resolve original binary behavior. Printed/PDF locators remain distinct and one-based. No proprietary rendered page is committed.

- **F-WPG — WPG byte order/record lengths** (SDK51 DR1–3; PDF204,205,206). DR1 prose says high byte/high short first while diagram labels low byte/low short first; DR3 separately gives special extended-length high-word-before-low-word encoding. Generic endian substitution is unsafe. Required witness: Original WPG with non-symmetric short/long fields and both extended-length forms; independently inspect bytes/records and original import/export outcome. Installed samples may be private candidates; no invented interpretation. Preserve unrecognized records and checked lengths.

- **F-LINK — Define Link End overlap** (SDK51 WP45–46; PDF58,59). D2/14 table places ending-row short at13 and filename at14; two-byte row would overlap. D2/15–16 below is marked WPWin DDE, distinct from DOS link functions. Required witness: Original DOS producer worksheet/link with nonzero distinguishable range coordinates and known filename lengths; compare Link Start/End before/after one range/path edit and F7/no-Perform versus F1. No shifted offset guess.

- **F-PACKET8 — Nonzero graphics index/extent** (SDK51 WP12; PDF25). Index length2 describes count; size-array begins2 with4 bytes per image; data starts2+4*count and continues by image sizes. Current approved framing accepts only count0. Required witness: Original one/two-image documents, full array/extent/body offsets, checked arithmetic/overlap/reference ownership, truncation/overflow corpus and unrelated-byte preservation; never use index length2 as total image extent.

- **F-FORMULA — Signed table formula positions** (SDK51 WP81–82; PDF94,95). Cell reference marker A6 precedes signed relative row/column shorts: row positive up/negative down; column positive right/negative left. This differs from common spreadsheet intuitions; table formulas differ from Column Math state. Required witness: Original table formulas referencing distinct nonzero cells in all four directions, zero-axis controls, source/result/cache and explicit recalculation after input edit; independently locate token/relative references before writer.

- **F-BORDERS — Older/newer table border widths** (SDK51 WP82–83; PDF95,96). Row border-byte-count high bit distinguishes newer short-per-column data from pre-release one-byte-per-column; toolkit says formatter converts older encoding. March applicability/safe normalization remains unobserved. Required witness: Provenance-cleared original old/new row fixtures with spans/counts/format/save effects, malformed width cases; no-edit Wordling export must stay exact even if original formatter rewrites its own save.

- **F-VARIANT16 — Locale/product-dependent type/packet identity** (SDK51 AP20; PDF519). Japanese DOS appendix identifies document/macro/keyboard types58/59/60 and packet16 font data; WPWin context uses packet16 for DDE. Numeric identity alone cannot determine semantic payload. Required witness: Exact Japanese original edition/profile/native fixtures and discriminant fields; independently reconcile US DOS/WPWin applicability without interpreting later-product DDE as DOS fonts.

## Reproducible qualification procedures

**Q-PROFILE — common acquisition and comparison gate.** First release/coordinate the exclusive VM lock; nothing here executes it. Obtain the exact resource via an identified owner-held/licensed source; record source description/URL, access/retrieval time, edition/locale/labels, rights holder or unresolved holder field, permission terms and redistribution disposition. Hash every archive/disk/system/resource/metric/font file before use. Keep master/media immutable; use a unique fresh-copy run root. Record parent baseline, original Help date, EXE/FIL/DRS/selected PRS/SET hashes, resource search paths, language/keyboard/display, emulator/firmware/CPU/RAM/RTC, OS/kernel/shell/config/codepage and FAT dates. Preserve raw start/end SET and output. Unknown fields block only dependent claims.

Archive exact runner/keystroke/settings trace, capture each prompt/capability/substitution, and retain native source/output/full original printer stream and hashes. Repeat accepted branches twice from fresh copies. State which single factor changed; simultaneous changes yield only combined-profile evidence. Record refusals, missing/wrong version/resource, cancelled actions, readonly/conflicting destinations and malformed inputs without invented message text. A clean prompt does not imply successful save. Source and unrelated bytes must survive failures. No verified label follows from documentary/self-generated evidence alone.

**Q-HIST — historical DOS corroboration.** No DOS version is selected by this register. After appropriate media/provenance exists, hash all boot/system files and CONFIG/AUTOEXEC; capture original runtime version/build/locale. Reuse the exact March WP executable/resources and current text control inputs, changing only OS/config dependencies. Replay elementary session/text controls in two fresh historical copies; compare native/print/state outcomes and keep every discrepancy. FreeDOS remains a separately declared profile; do not silently replace the target baseline or infer network/locking equivalence.

**Q-GFX — graphics fonts, metrics, printing and preview.** From available lawful media or a separately acquired original resource, identify an actually listed graphics-capable definition through original PTR/selection screens, not a guessed model name. Freeze definition/language specification and every resident/cartridge/downloadable font/metric dependency; record source/version/IDs/style/size/pitch/scaling/kerning/substitution, orientation/paper/feed/printable origin and job/quality/initialization/literal commands. A physical printer witness, if used, needs actual model/firmware/calibration/fonts rather than a driver name.

Run WP07 L1–L4 controls first under the complete declared profile, then L5 with two actually listed fonts including a proportional one and declared kerning changes. Retain complete L6 printer streams including initialization/terminators and original output choices. Before any positional comparison, freeze units/origin/baseline extraction/uncertainty and evidence-derived tolerance; never infer six-lines-per-inch from10cpi or use terminal wrapping as document geometry. Run L7 page-view modes/navigation/colors on matched pages/resources, preserving VGA/page bounds and print-before/after streams. Text Standard Printer success is not graphics/preview qualification. Headers/notes/tables/equations/wrapping/pagination combinations remain later independent comparisons.

**Q-LANG/Q-LOCALE — language and resource formats.** US identity is ready for bounded own-text Count1, language selection, Speller cancel and THES1 probes under WP10; exact prompts/options remain to be observed. Hash LRS/LEX/HYC/THS and actual selected paths before/after; main resources stay untouched. For SUP, first create a scratch original supplement using only project-owned invented words, retaining editable/compressed portions separately; independently audit native format/rights before publication. Wrong/missing dictionary, HYC or THS tests use disposable fresh profile copies and preserve source; no substitute modern spellchecker/thesaurus/collator.

For each retained locale, acquire its exact original edition/resources/provenance and capture the original Help language list, keyboard map, display/print glyph availability, character identities and resource paths. A language code alone qualifies neither a dictionary nor a font. Compare own native Compose/roundtrip, date/sort/reference-language placement, note continuation/Initial Codes, Speller/count/thesaurus and localized versus international macro interface independently. Preserve distinct native identities even when display glyphs coincide or are unavailable. Hebrew/Japanese/other original variant applicability is explicit research, not U.S. support or a hidden exclusion. No Unicode normalization/replacement or WPWin DDE interpretation may stand in for DOS native behavior.

**Q-SHEET — original worksheets and persistent links.** Select one actual publication-listed producer/version with its complete record specification and lawful scratch producer. Create project-owned A1:B2 labels/value/formula with saved cached result and excluded sentinel; capture encoding/dimensions/format/range/date/number/calculation-save state. Confirm original accepts it before implementation. Compare Text and Table output separately; table output needs accepted structural contracts. Hash source unchanged. For LINK1 separately capture original Perform, F7/no-Perform and F1/cancel, path/range/timestamp plus stale/refreshed region, then source-change/recalculation/update/retrieve and missing/conflicting cases. Resolve F-LINK from actual original fields before decoder/writer; do not evaluate a modern formula library and call that original import behavior.

**Q-CONVERT — each original converter/mode.** Retain CONVERT, MACROCNV, GRAPHCNV and native4.2/5.0, DOS/Generic/other original Text Out modes as distinct workflows. Binary presence is not source producer/input/codec qualification. Obtain a rights-cleared original-version source/specification and freeze options/resources/loss policy for one mode at a time; record original report/unsupported commands, output bytes/version and original reopen/edit/execute or print comparison as applicable. Test absent/overwrite/cancel/malformed/loss branches in scratch copies; source untouched. Retain STANDARD.CRS identity separately from conversion behavior. Permanent native Save stays direct original format, independent of converting through another word processor or exporting PDF.
