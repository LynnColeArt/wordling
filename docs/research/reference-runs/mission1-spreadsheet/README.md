# Worksheet import and refresh: DOS observations

The [worksheet](RANGE.WK1) is generated by [fixture.py](fixture.py).
It has labels and integers in A1:C3, with distinct values outside
the target range.

Ctrl+F5, Spreadsheet (5), Import (1) accepts the filename and a
range written as `A1..B2`. Type defaults to Table. Perform Import
(4) creates a compact two-column table with that range only. DOS
left aligns the labels and right aligns the integer.
[Import settings](range.txt) · [Screen](imported.txt) ·
[Native document](IMPORT.WP)

Create Link (2) with the same settings surrounds the imported
table with separate Link and Link End records. Those records
retain the source filename, and the opening record also retains
the selected range. The link initially displays the cached result
7 even after the worksheet is changed to 19. Ctrl+F5, Spreadsheet
(5), Link Options (4), Update All Links (3) refreshes it to 19.
[Link](LINK.WP) · [Refresh choice](link-options.txt) ·
[Refreshed screen](updated.txt) · [Refreshed document](UPDATED.WP)

The second [input worksheet](OFFSET.WK1) has a negative value in B2.
Selecting B2..C3 produced a [signed result](offset.txt) and
[matching native table](OFFSET.WP). The original Standard Printer
streams for [import](IMPORT.PRN), [link](LINK.PRN) and [offset
range](OFFSET.PRN) also serve as exact byte comparisons. The link
boxes do not print.

Wordling implements CMD51-136 and CMD51-137 for two-by-two Lotus
WK1 tables containing default-format ASCII labels and signed
integers. It creates the table in a blank document. A saved link
shows its cache on retrieval; Update All Links reads and replaces
that one cache, conserving the document on a read error and
leaving the worksheet untouched. Larger ranges, other cell
formats, text output, automatic refresh and editing links remain
outside this profile.
