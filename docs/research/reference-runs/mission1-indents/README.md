# Double indent and hanging indent

Shift+F4 moves both margins inward. A hard return resets both.
F4 followed by Shift+Tab starts a hanging indent. WordPerfect writes
a margin-release code for the first line and keeps the left indent on
the following lines. Linux matches the onscreen columns and the
native body for both paragraphs. [Reveal Codes](reveal.txt) · [Native save](INDENTS.WP)

The captured print stream distributes the extra spaces differently on
the justified first lines. That printer behavior remains open.
[Printer output](INDENTS.PRN)
