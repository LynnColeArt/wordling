# Marking a full legal authority: DOS observations

Block `Sample v. Example`, press Alt+F5 and ToA (4), and enter
section 1. The full-form editor starts with the selected citation.
F7 accepts the full form, then Enter accepts the default short form.
The original citation stays in the document, preceded by a native
D7/04 mark that contains the section, short form, and full form.

Wordling matches that native body and Reveal Codes. The sampled
workflow covers single-line plain text; formatted citation editing,
standalone short forms, and generation remain open.
