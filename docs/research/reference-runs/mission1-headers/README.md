# Headers and footers

Format → Page → Headers or Footers opens slot A or B, then chooses
every, odd, or even pages. Short printable-ASCII text is stored in a D5
owner. WordPerfect reserves the header and footer space in the document's
end-of-page records. Linux matches the native bodies of the captured
documents and both captured Standard Printer streams.
[Reveal Codes](reveal.txt) · [Every-page header and even-page footer](HEADFOOT.WP) ·
[Printer output](HEADFOOT.PRN) · [Odd-page header and every-page footer](MASKS.WP) ·
[Printer output](MASKS.PRN) · [Even-page footer only](FOOTONLY.WP)

Discontinue inserts an empty D5 control and restores the first-line baseline
from the next affected page. [Native save](DISCONT.WP)

Editing existing running text, richer nested text, and interactions with
asymmetric page margins still need qualification.

Run the replay scripts from the repository root with `PYTHONPATH=scripts/reference`.
