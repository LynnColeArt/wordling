# Mark a table-of-contents heading

Select the heading with Block, then press Alt+F5. In the March 9,
1992 DOS release, 1 selects ToC. Enter a level from 1 to 5 and press
Enter. WordPerfect clears the selection and writes a pair of D7
owners around the selected text.

Wordling matches the native body at both captured levels, 1 and 5.
The marks appear in Reveal Codes and occupy no printed space.
Generating a table of contents from the marks remains open.
