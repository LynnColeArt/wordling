# Document comment

Ctrl+F5, Comment (4), Create (1) opens a private editing area. F7
inserts the comment into the document. It appears in a double-line
box in the DOS editing view and as [Comment] in Reveal Codes.
It consumes no printed lines.

Wordling matches the native body and Standard Printer output for
the captured printable ASCII comment. Editing existing comments,
conversion, rich content, and the hide-comments setting remain open.
