# Thesaurus lookup and cancel: DOS observations

Put the cursor on `quick` in `quick fox` and press Alt+F1.
The original displays several synonym groups and an antonym
group for the word. F1 cancels and restores the document at the
same position. The [saved body](CANCEL.WP) remains `quick fox`.
