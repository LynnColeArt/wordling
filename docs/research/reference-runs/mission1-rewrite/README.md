# Rewrite screen

Ctrl+F3 opens the Screen prompt. Choose 3 or Enter to refresh
the editing display. In the default automatic formatting profile
the captured text, caret and status match before and after the
command. Wordling rebuilds its editing projection without
changing the native revision or moving the caret.
