# Line numbering

Format → Line → Line Numbering inserts a D3 subfunction 5 owner.
The original editing canvas shows the ordinary document text. Reveal Codes
shows the on and off codes, and the Standard Printer writes the numbers
in the left margin. The test checks explicit on and off, sequential
numbering of three lines, and surrounding unnumbered paragraphs.
[Native save](LINENUM.WP) · [Reveal Codes](reveal.txt) · [Printer output](LINENUM.PRN)

Run the replay scripts with `PYTHONPATH=scripts/reference` from the repository root.
