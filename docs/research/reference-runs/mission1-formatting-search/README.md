# Search for an Underline code in WordPerfect 5.1 DOS

Type the literal text `[UND]`, a space, and a separately underlined
word. Return to the beginning and open Reveal Codes. F2, F8, F2
searches for the native Underline On code and moves to Pos 1.6".
Typing X at that position places it inside the underlined word.
