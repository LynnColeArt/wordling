# Footnotes and endnotes

Ctrl+F7 opens the note menu. The original creates a separate editing
surface for the note and returns to the reference when F7 closes it.
A footnote and an endnote each start their own numbering at 1. The native
body stores the note text inside a D6 owner. [Reveal Codes](reveal.txt) ·
[Native save](NOTES.WP) · [Two notes of each type](NOTES2.WP)

The Standard Printer fixture prints the footnote above the bottom margin
with a separator. It places the endnote on a following page. Linux matches
that byte stream for the captured short notes. [Printer output](NOTES.PRN)

Linux creates short printable-ASCII notes in document order and can edit
them by number. The edit changes only the selected native owner.
[Edit prompt](edit-prompt.txt) · [Edited save](NOTEEDIT.WP)

Longer or formatted text, continuation constraints, and alternate
endnote placement remain open.

Run the replay scripts from the repository root with `PYTHONPATH=scripts/reference`.
