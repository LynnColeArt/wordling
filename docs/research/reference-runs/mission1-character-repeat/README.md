# Repeat one character in WordPerfect 5.1 DOS

In a fresh document, press Escape, enter 5 and type `x`. DOS inserts
five characters. A subsequent `q` is inserted once, so the native body
is `xxxxxq`. Wordling passes the same terminal sequence. The initial
default shown by the DOS prompt and other repeat contexts remain outside
this comparison.
