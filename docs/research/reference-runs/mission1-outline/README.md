# Successive outline levels: DOS observations

In a blank document, Shift+F5, Outline (4), On (1), then Enter
creates the first outline entry. Type `First`, then press Enter
and Tab to change the next entry to the second level. Type `Child`.
The default outline shows `I.First` and an indented `A.Child`.

[Reveal Codes](reveal.txt) shows Outline On followed by ordinary hard
returns and separate automatic paragraph-number records. For the
second level there is also a native Tab. The condensed
[native save](OUTLINE.WP) contains those individual owners.

Wordling authors the default first and second levels in a blank document
and matches the original body and [Standard Printer bytes](OUTLINE.PRN).
Other numbering schemes, deeper levels, and outline family operations remain open. Run `replay.py` from the repository
root with `PYTHONPATH=scripts/reference`.
