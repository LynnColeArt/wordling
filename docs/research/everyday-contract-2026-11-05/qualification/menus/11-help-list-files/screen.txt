List

     Displays a list of files or equation commands, depending on when you press
     this key.  Pressing List (F5) at the normal editing screen invokes the
     List Files feature which lists all files that match the filename template
     (pattern) given.  When WordPerfect displays the template (e.g.,
     c:\files\*.*), press Enter to display all the files in the current default
     directory, or edit the template to display the directory and files you
     wish to view.

     To perform an action on a file, move the cursor to the file before
     selecting the action.  To perform an action on several files at once, mark
     each of the files (either move to each file and press *, or mark all the
     files in the directory with Home, * or Alt-F5) and then select the action.
     You can then delete, print, copy, or search the marked files.  To print
     the directory listing, press Print (Shift-F7).

     Pressing List at a "Filename:" prompt (e.g., Graphics Box Definition,
     Style Definition) allows you to use List Files to find and retrieve a
     file.  Pressing List in the Equation Editor moves the cursor to the list
     of equation commands.
