# Mission 1 command audit

This audits all 244 command scenarios against the Linux implementation and existing WordPerfect 5.1 DOS evidence. A scenario can represent one branch of a larger feature. These counts measure scenario coverage, and they do not estimate effort or close the Mission 1 acceptance matrix.

| Status | Scenarios | Meaning |
| --- | ---: | --- |
| Verified | 186 | Implementation and DOS-backed qualification cover the inventoried behavior in the admitted profile. |
| Partial | 36 | A related implementation or narrower qualified branch exists. The listed behavior still has a coverage or implementation gap. |
| Unimplemented | 22 | No working entry point for the listed behavior was identified. DOS-only observations and menu placeholders do not count as implementation. |

The audit records evidence anchors without changing the historical inventory’s original observation fields. Earlier verified scenarios may need a fresh run before final acceptance.

## Order of work

1. Close focused differences in existing editing commands, starting with formatting-code search. Then tackle file operations and common original text import. These affect everyday documents and have clear DOS comparisons.
2. Expand ordinary layout and structured documents, starting with margins, paragraph alignment, headers, footers and notes. Verify native saves and printed layout before adding dependent styles and generated documents.
3. Close macro recording and execution gaps, sorting, table calculations and spreadsheet workflows. Use the existing DOS fixtures to prioritize control flow and native companion files.
4. Implement the remaining graphics, equations, printer and language resources, converters and utilities. Finish with the complete DOS differential run and acceptance review.
