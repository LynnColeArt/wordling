Help                                                   WP 5.1   03/09/92


     Press any letter to get an alphabetical list of features.

          The list will include the features that start with that letter,
          along with the name of the key where the feature is found.  You
          can then press that key to get a description of how the feature
          works.


     Press any function key to get information about the use of the key.

          Some keys may let you choose from a menu to get more information
          about various options.  Press HELP again to display the template.
